# Lumina API

API Laravel terpisah untuk CRUD products dan users pada aplikasi Lumina. API memakai PostgreSQL dan mempertahankan bentuk response yang digunakan frontend di folder `crud`.

## Menjalankan

1. Pastikan PHP, Composer, ekstensi `pdo_pgsql`, dan PostgreSQL tersedia.
2. Sesuaikan kredensial database serta `ADMIN_*` di `.env`.
3. Jalankan migration dan seed admin:

```bash
php artisan migrate --force
php artisan db:seed
```

4. Jalankan API pada port yang digunakan frontend:

```bash
php artisan serve --host=127.0.0.1 --port=3001
```

Endpoint tersedia di `/api/health`, `/api/auth/login`, `/api/products`, dan `/api/users` dengan method CRUD yang sesuai.

## OTP dan MFA

MFA dapat diaktifkan per user dari form **Users** melalui opsi **Enable email OTP MFA**. Saat login berikutnya, user memasukkan kode OTP 6 digit yang berlaku selama 10 menit dan hanya dapat digunakan sekali.

Untuk development, `.env` lokal memakai `MAIL_DRIVER=log`; kode OTP dapat dilihat di `storage/logs/laravel-YYYY-MM-DD.log`. Untuk mengirim OTP ke email sungguhan, salin konfigurasi SMTP dari `.env.example` ke `.env`, lalu isi `MAIL_HOST`, `MAIL_PORT`, `MAIL_USERNAME`, `MAIL_PASSWORD`, `MAIL_FROM_ADDRESS`, dan `MAIL_FROM_NAME`. Jangan commit `.env` atau membagikan password SMTP.

## Catatan runtime

Project ini menggunakan Laravel 12 dan membutuhkan PHP 8.2 atau lebih baru. PHP 8.2 dengan `libpq` modern mendukung autentikasi PostgreSQL SCRAM.
